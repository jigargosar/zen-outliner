## Working Features

- Tree display with nested nodes
- Arrow key navigation (up/down/left/right)
- Collapse/expand parent nodes (click bullet or left/right keys)
- Inline editing (Enter to edit, Escape to cancel)
- Done toggling (Space, shows strikethrough)
- Click to focus, double-click to edit
- Mode indicator (NAV/EDIT) at bottom
- Dark theme with Tailwind
- Focus follows scroll (auto scroll-into-view)
- Batch signal updates for atomic state changes

## Missing (next milestone)

- Add new nodes (Enter = sibling)
- Delete nodes (Backspace on empty)
- Indent/outdent (Tab / Shift+Tab)
- localStorage persistence (tree + focus + collapsed state)
- Visual polish

## Known Issues (not blocking)
